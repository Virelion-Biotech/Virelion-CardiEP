# Third-party references and licensing

CardiEP is AGPL-3.0-or-later.

The native CardiEP implementation is independently written. It was designed after reviewing public scientific software including Cardiac-Digital-Twin, FEniCSx-beat, MonoAlg3D, openCARP, Chaste, cbcbeat, pyCEPS, Cobiveco, cardiac-geometries/LDRB, gotranx, and related Purkinje-network work.

No third-party source tree is vendored in this repository.

Permissively licensed projects may inform future ports, but any copied or substantially derived code must preserve the upstream copyright and license notices. Restricted or differently licensed engines should remain external processes or plugin dependencies unless a deliberate licensing review says otherwise.

See `docs/RESEARCH_MAP.md` for the current integration map.
